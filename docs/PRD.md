# 三视图 ThreeViews · 产品需求文档 PRD

版本 1.0.0 · 2026-10-02 · PICO OS 6 (Project Swan) · PICO Spatial SDK 6.1.9

## 1. 一句话 One line

把工程制图课里的三视图做成空间应用：给一个 3D 机械零件，把主视图、俯视图、左视图分别投影到三个真实存在的投影面上，再把三个面摊平成一张国标图纸。

The three-view drawing from engineering graphics class as a spatial app: a 3D part is projected onto three real planes in front of the user, then the planes unfold into a GB first-angle sheet.

## 2. 背景与问题 Background

- 工程制图的第一道坎是空间想象：零件、三个互相垂直的投影面、三个投影方向之间的关系，课本只能用一张角度定死的轴测图加箭头表示。
- CAD 软件给的是三个并排的 2D 视口，看不到"投影"这个动作本身。
- 头显里的 Shared Space 可以把投影箱放到桌面上，让人绕着看、探头沿投影方向看过去，看到的就是那个视图。这是平面做不到的。

## 3. 用户与场景 Users and context

| 项 | 内容 |
| --- | --- |
| 用户 | 学过或正在学工程制图的学生、工程师 |
| 场景 | 坐在桌边戴头显，一次 5 到 15 分钟 |
| 空间 | Shared Space，投影箱在手边，可以从任意一侧观察 |
| 语言 | 界面中英双语同时显示（中文在前，英文跟随） |

## 4. 唯一任务 The single job

让人亲眼看到一个零件怎样变成主、俯、左三个视图，并能对着零件把图纸上每一条线读明白：可见轮廓粗实线、不可见轮廓虚线、轴线点画线，以及长对正、高平齐、宽相等。

## 5. 为什么要做成空间应用 Why spatial

| 核心任务 | 空间版为什么更好 | 2D 对照 |
| --- | --- | --- |
| 理解三个投影面的位置关系和投影方向 | 三个互相垂直的面和三个投影方向是真的 3D 关系，探头沿投影方向看过去，看到的就是那个视图 | 课本是一张角度定死的轴测图；CAD 是三个并排的 2D 视口 |
| 把零件上的一条棱对到视图上的一条线 | 投影线从棱上的点发出落到面上，起点和落点同时在眼前；换个角度还能看到被挡住的棱为什么是虚线 | 平面上只能靠编号对应，被遮挡的结构只能在脑子里想 |
| 理解图纸为什么是主视图左上、俯视图在下、左视图在右 | H 面向下翻、W 面向右翻，三个面摊成一张纸，这个动作本身就是答案 | 课本用两张图加箭头 |
| 选零件、读图、核对三等关系 | 保持 2D：这部分就是一张图纸和一个列表，平面最清楚 | 就用平面做 |

## 6. 形态与布局 Form and layout

Shared Space 里的三个表面，从左到右：

| 表面 | 类型 | 内容 | 默认尺寸 | 范围 |
| --- | --- | --- | --- | --- |
| 投影箱（主窗口，居中） | Volumetric，系统管理的动态尺度，不显示底板 | 零件、V/H/W 三个半透明投影面、投影线、三个中英文名牌；下方窗口级工具条 | 0.8 × 0.72 × 0.9 m | 系统默认 |
| 零件库窗口（左侧，启动时打开） | Planar | 八个内置零件的列表：编号、中英文名、结构说明、难度 | 360 × 720 dp | 320 × 480 到 480 × 960 dp |
| 图纸窗口（右侧，按需打开） | Planar | 国标第一角画法图纸：投影轴、45° 线、三个视图、对齐线、标题栏；下方一个"对齐线"开关 | 960 × 720 dp | 720 × 540 到 1600 × 1200 dp |

投影关系按 GB 第一角画法：主视图在零件后方的 V 面，俯视图在零件下方的 H 面，左视图在零件右侧的 W 面。展开时 V 面不动，H 面绕 OX 向下翻，W 面绕 OZ 向右翻，摊平后的箱子就是图纸；零件离开三面角，落到第四象限成为一个小轴测参考。

## 7. 功能需求 Functional requirements

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| F1 | 内置 8 个由 CSG 实体定义的零件（L 形块、阶梯块、斜切块、带孔底板、V 形块、槽块、轴承座、开口管），由算法精确算出可见线、不可见线、中心线 | 必须 |
| F2 | 投影箱里实时显示零件和三个面上的投影；投影线把零件棱上的点送到面上 | 必须 |
| F3 | 分段控件（全部/主视/俯视/左视）、点投影面、点图纸上的视图，三种方式聚焦一个投影方向 | 必须 |
| F4 | 展开/合上动画；展开后零件落到第四象限做轴测参考 | 必须 |
| F5 | 投影线、虚线两个开关（投影箱），对齐线开关（图纸） | 必须 |
| F6 | 横向拖动转动整箱（±80°），复位回到 28° 教科书视角；摊平时不可转动 | 必须 |
| F7 | 工具条上的"零件库""图纸"两个开关打开或关闭两个 2D 窗口并显示其状态 | 必须 |
| F8 | 图纸：视图名、三等关系对齐线、标题栏（名称、比例、图号、单位、第一角画法符号）全部中英双语 | 必须 |
| F9 | 视图计算失败时在图纸上给出错误占位和"重试"，图纸窗口未开时自动打开 | 必须 |
| F10 | 尺寸标注 | 以后 |
| F11 | 练习模式：补画或选出缺的第三视图，由投影本身判卷 | 以后 |
| F12 | 导入 STL / glTF 模型走同一条投影管线 | 以后 |

## 8. 非功能需求 Non-functional

- 全部 2D UI 使用 SpatialUI（`com.pico.spatial.ui.*`）并包在 `PicoTheme` 里，不使用 Material/Material3。
- 3D 运行时行为在 ECS 侧（`BoxAnimationSystem`、`BoxSceneController`），Compose 只负责面板和控件。
- 网格、材质、碰撞体在后台线程创建；所有跨实体复用的资源 `toGlobal()` 并显式 `close()`。
- 换零件后 1 秒内出图（启动后在后台预热零件库）。
- 单元测试覆盖 ViewModel、UseCase、仓库和投影算法（当前 91 个）。

## 9. 视觉 Visual

主题来自制图桌：描图纸（#F6F3EA）、墨线（#16181C）、蓝铅笔的作图线和交互色（#2B5FD9）、红铅笔的点画线（#C4372B）。三个投影面分别是淡蓝、淡黄、淡绿。窗口根保持系统玻璃材质，纸面是窗口内的不透明卡片。字体 Noto Sans SC。

## 10. 验收 Acceptance

- 启动后投影箱在用户正前方可见，零件库在左侧打开。
- 选任一零件，三个面上的投影与图纸一致；聚焦、展开、投影线、虚线、对齐线、转动、复位按第 7 节工作。
- 模拟器 PICO 6.1 上完成全部交互验证并录制演示视频；真机验证待做。

## 11. 已知限制 Known limits

- 尚未在真机上验证物理尺寸、舒适度、手势交互和性能。
- 模拟器上首次出图需要数秒（模拟器翻译 ARM 代码），真机预期明显更快。
